What this page counts, and what it deliberately does not. “Needs an analyst” is Miscategorised only — a line in the wrong branch where we can say where it belongs. Out of scope is a scope finding and is never counted as an error. Re-mapped is a migration we caused, not a hospital mistake, and is bulk-approvable. Incomplete is a gap, not an error.

Figures come from the live three-model jury (NIM_*), never the older single-model layer. Spend is signed, exactly as the data holds it — no threshold, no netting, no absolute values — and is shown as figures rather than a bar because a stacked proportion bar cannot draw a negative segment. Line counts sit beside every spend figure so you can see when one rests on a handful of rows.
